ОТКРЫТКА ДЛЯ ВЕРОНИКИ

Файл index.html — готовый сайт, который можно открыть в браузере.

Как опубликовать бесплатно через GitHub Pages:
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи index.html в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, ветку main и папку /(root), затем Save.
5. Через несколько минут GitHub покажет ссылку на сайт. Отправь её Веронике.

Текст можно менять прямо в index.html обычным текстовым редактором.
